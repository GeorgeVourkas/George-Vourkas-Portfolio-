AI Recipe Generator - Cook with What You Have

Built with React and powered by the Claude AI API, this app helps you turn your ingredients into delicious recipes. Simply enter what you have in your kitchen, and get instant, creative recipe suggestions. Plus, never lose a favorite meal again, save your top picks directly to the integrated Spring Boot and PostgreSQL library for easy access later. Quick, easy, and fun-your personal AI cooking assistant.

Recipin - Save Recipes in One Click

Recipin is a modern, minimal Chrome extension designed to make saving recipes effortless. Just type a name and hit save - the extension automatically stores the page URL using the Chrome API. With its clean and intuitive interface, Recipin keeps your favorite cooking ideas organized and just a click away. Simple, sleek, and built for everyday use.

Weather App - Simple & Accurate Weather Updates

Built with React and powered by the OpenWeather API, this app provides real-time weather information for your location. Check the current temperature, weather conditions, and basic details like humidity and wind speed, all in a clean and easy-to-use interface. Stay informed and plan your day effortlessly.

Global Landmarks API - Explore Unique Places Worldwide

A Node.js REST API built as a backend service that provides structured data about unique natural locations around the world. The API supports filtering via URL query parameters and was developed and tested locally as a backend-only project.
